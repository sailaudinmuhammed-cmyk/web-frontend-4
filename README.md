| Task | File | Requirements covered |
| --- | --- | --- |
| 0 | `index.html` | Name, email, message, labels and submit button |
| 1 | `task1.html` | Native HTML5 required fields, email type and maximum lengths |
| 2 | `task2.html` | Bootstrap controls, responsive grid, placeholders and helper text |
| 3 | `task3.html` | JavaScript toggles `is-valid` / `is-invalid` and shows feedback |
| 4 | `task4.html` | Names, email, matching passwords, gender radios, optional hobby checkboxes, country, submit and reset |

`styles.css` contains the small shared stylesheet. `forms.js` handles demo submission and Bootstrap validation. Tasks 0–2 retain native browser validation. Tasks 3–4 use the browser's validity API with Bootstrap feedback; `novalidate` is enabled by JavaScript only. No backend is included. Submissions never transmit or store data or passwords.
